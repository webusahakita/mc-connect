Pertanyaan Umum Pembeli Software

❓ Apakah aplikasi ini bisa dipasang nama panggung dan foto saya sendiri?

Tentu saja, 100% White-Label. Anda memiliki kontrol penuh melalui menu Admin Workspace > CMS Konten untuk mengubah nama panggung, foto profil avatar, tautan media sosial (Instagram, TikTok, Facebook), katalog paket harga, dan ketentuan riders panggung tanpa coding.

❓ Bagaimana cara mengoperasikannya saat tampil di panggung?

Sangat mudah. Anda cukup membuka browser di tablet (iPad atau Android tablet) lalu mengakses alamat web panggung (`/stage`). Layar panggung dirancang gelap kontras tinggi OLED dengan tombol sentuh ekstra besar, deteksi suara otomatis *Speech-to-Scroll*, dan indikator segmen acara.

❓ Apakah saya harus membayar sewa bulanan atau biaya per booking?

Tidak ada biaya langganan bulanan maupun potongan komisi per booking. Sistem kepemilikan software bersifat One-Time Purchase (Beli Sekali), dan aplikasi dapat di-hosting pada shared hosting murah atau VPS Anda sendiri.

❓ Bagaimana jika koneksi internet di dalam gedung/ballroom hotel mati?

MC-Connect dilengkapi teknologi modern Progressive Web App (PWA) dengan *Service Worker* lokal. Naskah acara yang sudah termuat akan tetap tersimpan di memori perangkat, efek suara soundboard tetap dapat dimainkan, dan timer tetap berjalan akurat tanpa internet.
