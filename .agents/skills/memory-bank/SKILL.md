# Memory Bank Skill

The Memory Bank maintains project context across conversation turns and sessions.

## Core Files & Structure
- **productContext.md**: Why this project exists, user problems it solves, core business goals.
- **activeContext.md**: Current focus, recent changes, active decisions, next immediate steps.
- **systemPatterns.md**: System architecture, key technical patterns, component relationships.
- **techContext.md**: Technologies used, dependencies, constraints, environment configuration.
- **progress.md**: What works, what is built, what is left to build, known issues.

## Guidelines
1. Read the memory bank at the start of a task to establish context.
2. Update the memory bank whenever significant decisions or architectural changes are finalized.
3. Keep entries concise, structured, and factual.
